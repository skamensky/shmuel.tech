Privacy policy

This policy describes how Shmuel Automation handles Google user data.

Scope

Shmuel Automation is a personal command-line tool operated by Shmuel Kamensky. It is intended for the operator's own accounts rather than as a service for the general public.

Data the tool may access

Subject to the permissions granted through Google OAuth, the tool may access Google profile information and data in Gmail, Contacts, Calendar, Drive, Docs, Sheets, Slides, Forms, Tasks, and Apps Script. This can include messages and attachments, drafts, contact details, events, files and document contents, form content and responses, task data, and Apps Script project or operational information.

How data is used

Data is used to execute actions requested by the operator, such as searching, reading, creating, editing, organizing, exporting, downloading, or sending information. The tool is not intended to use Google user data for advertising or to build profiles for unrelated purposes.

Storage and retention

OAuth credentials, cached API responses, metadata, downloaded content, and command outputs may be stored on systems used to operate the tool. What is stored and for how long varies with the command, operational needs, and manual cleanup. Revoking Google account access prevents future API access but does not automatically remove copies that were previously created outside Google.

Sharing

The tool is not intended to sell Google user data or disclose it for advertising. Data may be processed by Google, hosting or software providers used to operate the tool, sent to a destination selected by the operator, or disclosed where required by law.

Google API data

The tool's use and transfer of information received from Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements.

Controls and requests

Google access can be reviewed or revoked through the Google Account permissions page. Questions or requests concerning data handled by the tool may be sent to shmuelkamensky@gmail.com. Requests may require identity or account verification and will be handled as applicable to the circumstances.

Security

Reasonable measures may be used to limit access to the systems operating the tool, but no storage or transmission method can be guaranteed to be completely secure.

Changes

This policy may be updated as the tool or its data practices change. The date at the top identifies the current published version.
